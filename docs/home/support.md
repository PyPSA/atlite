# Support

- To **discuss** with other PyPSA and atlite users, organise projects, share news, and
  get in touch with the community, join the [Discord server](https://discord.gg/AnuJBk23FU).
- For **bugs and feature requests**, use the [issue tracker](https://github.com/PyPSA/atlite/issues).
- We welcome anyone interested in **contributing** to atlite. If you have ideas or
  suggestions, or encounter problems, please open an issue or a pull request on
  [GitHub](https://github.com/PyPSA/atlite). See the
  [contributing guidelines](../contributing/contributing.md).

!!! note

    Questions are easier to answer with a minimal working example that shows the
    problem, together with the approaches you already tried.
